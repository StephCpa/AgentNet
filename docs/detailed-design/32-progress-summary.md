## 1. 设计收敛与复审结论

总体仍采用 GW 入站、ICS 授权、TCS 权威事务、持久投递与执行恢复的职责划分。Agent 提出意图，控制面校验后才产生权威事实；这些逻辑职责可合并部署，不要求每一项都是独立服务。

| 主题 | 当前采用的规则及修正 |
| --- | --- |
| 预算 | 按维度维护 `S + H + D ≤ B`；预留独占绑定，允许同一 effect 绑定多维预留。复审修正了错误方向的唯一索引。未知结果保留 HELD，异常超额保留实际证据并冻结新支出。 |
| 幂等与事实 | command 绑定原参数、签名与可信期限；历史接纳恢复原回执，过期重放拒绝。effect 冲突单独记账，不覆盖原状态、参数及预算。已有 effect 的合法重试优先恢复事实，避免被自身版本递增拒绝。 |
| 执行权 | 已认证实例必须绑定租约持有者；提案 epoch 单独检查。授权决定绑定操作上下文，权威父链在决定、接纳、发送三个执行点复核。 |
| 委派 | 本域子任务创建原子绑定接收方、收缩授权和子预算；父账 H→D，子账建立。取消通过持久工作传播；UNKNOWN 未解决时不提前归还预算，结清只执行一次。 |
| 契约 | 新接纳共用结构校验与离线 JSON Schema 2020-12 编译；迁移 015 固定契约内容及任务引用。旧 ACCEPTED 精确恢复保留，新规则需要新版本和新任务。 |
| 协议与验收 | 仓库冻结 A2A v1.0.1 线格式基线，MCP 协议任务态、effect 结果与本地验收分开。`COMMITTED` 不等于 `VERIFIED`，分区归档不等于 ART。 |

复审撤回了早期“全部 P1/P2 已完成三层验证”“M3 属于预期冗余”“TLA 不支持 `=>`”等结论。旧模型未观察提案代次，不能据此证明守卫冗余；修正后持有者绑定与代次检查分别可被反例检验。旧版 13,290 状态、7/8 变异的结果不作为当前模型证据。详见 [复审记录 15](15-review-remediation.md) 与 [形式模型说明](../../test/tla/README.md)。

## 5. 下一阶段与完成标准

1. **先补证据验收闭环**：按 [09](09-evidence-and-context.md) 实现不可变产物、披露策略、版本化证据清单和受信验证器；绑定 VERIFIED 四元组，接通 `UpdateTaskStatus` 成功守卫。以成功验收、篡改/错版本/越权拒绝及重启补取作为验证入口，完成相应 FI-09 场景。
2. **补完整入口与真实协议**：继续 agentgateway 挂接、完整 SDK、OAuth/DPoP、配额/披露检查、接收方策略管理及生产身份配置；冻结可靠接纳扩展并用独立 A2A/MCP 对端跑 PRT，核验已登记的 GET/POST 等差异。
3. **推进跨域与模型扩展**：目录和三域同步、跨域授权映射、预算转移/结清；扩展崩溃相位、预留/attempt 归属、重复消息、子任务树和验收证据模型，再对照 [13](13-verification-and-testing.md) 与 [14](14-mvp-plan.md) 逐项复审里程碑退出条件。
4. **最后完成规模与运维验证**：完整 FI/BM、生产负载和容量、备份恢复及故障切换演练。现有微基准不替代这些工作。

后续每个实现增量继续保存“具体缺陷或需求 → 设计变化 → 正反例与故障证据 → 尚未覆盖范围”的记录；本小结作为接续工作入口，历史详细记录与原始证据保持可追溯。
