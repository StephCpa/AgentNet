## 4. 首版必须做实的四件事（验收红线）

1. **每次操作都有明确身份与授权**——01/06 全链路无匿名生效路径；
2. **任务交接、重复消息、进程重启不破坏权威状态**——FI-01/02/07/08 全绿；
3. **资源可预留可结算，UNKNOWN 保留真实不确定性**——FI-03/06/12 全绿，无自动重做路径；
4. **结果与证据可被后续 Agent 获取和核查**——FI-09 全绿，`VERIFIED` 仅经验收器签发。

在此闭环验证通过前，不合并学习型路由、自动组队、语义压缩与 DP 共享（每个智能能力后续单独评估收益、开销与对保证的破坏，13 §5 消融框架即为此准备）。

## 5. 风险登记（Top）

| 风险 | 缓解 |
|---|---|
| agentgateway 可复用度低于预期（OQ-1） | 自研最小流水线兜底，接口已按可插拔定义（08 §7） |
| A2A/MCP 规范细节与 08 映射有出入 | [核对项] 机制 + PRT 回归拦截 |

| 基准显示 B2/B3 已达到同等保证 | 按总体方案 §14.3 调整主张：价值转整合与使用体验，研究点转方向 A/B/C |
