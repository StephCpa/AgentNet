# AgentNet 详细设计（v0.2.2）

本目录是《Agent 网络系统总体设计方案》（2026-10-24，下称**总体方案**）的详细设计（Detailed Design）。总体方案回答"系统应该是什么样、为什么这样"；本目录回答"具体怎么做"：模块边界、数据模型与 DDL、状态机与事务边界、接口定义、协议适配规则、故障恢复流程、验证计划与实施步骤。

## 设计基线声明

- 协议版本基线：**A2A v1.0.1（线上协议版本 1.0）**、**MCP 2026-07-28**；适配器冻结版本，升级需重新过 08 的映射核对表。
- 日期基线：2026-10-24。凡引用外部规范状态处，以总体方案 §2 调研结论为准。
- 单域事务内核、本域投递、业务恢复、受限 mTLS/ICS、OIDC 用户同意、手动/自动凭证轮换与 SDK 网关签名/审计已实现并进行 PG16、进程终止和网络验证（16–23）；委托、完整 GW、真实目标、跨域闭环与压测尚未完成；所有参数默认值为**初始建议值**，需按 13 的基准结果修订。
