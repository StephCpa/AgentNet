# 11 · 披露控制与差分隐私设计

状态：v0.1 草案 ｜ 上游：总体方案 §12 ｜ 前置：06、09、10

## 1. 职责划分

- **披露控制（09 §5 执行）**：管"特定接收者能否看到特定内容"，逐条判定、可拒绝、可审计——管的是**定向传播**。
- **差分隐私（本文件 §4–§6）**：管"面向统计/学习反馈的**公开聚合输出**"对单个用户记录的影响——管的是**发布**。
- 二者不互替：DP 不授权任何人读原文；披露标签不因加噪而放松。

## 2. 披露控制执行点（汇总）

GW 出站载荷检查 / 模型调用出域 / ART 读取与再转交 / 补取 / 日志白名单（09 §5、10 §1、§4）。派生继承与去分类流程见 09 §3。**观察系统本身最小化**（默认字段集、内容 opt-in）已在 10 落地。

## 3. 面向 DP 的数据面

DP 只作用于 §4 声明的发布用途，输入为**本域回执与账本**（不采集跨域对端的原始任务记录）：

| 用途 | 相邻关系中的"单位" | 输出形态 |
|---|---|---|
| 能力类别可靠性统计（联邦共享） | 一位用户 | 某能力类别近期成功率（分桶计数） |
| 跨租户任务分布 | 一位用户 | 任务类别×时段分布 |
| 共享路由反馈（研究项，方向 C） | 一位用户 | Q̂ 校准特征 |
| 平台级性能趋势 | 一位用户 | 聚合时延/成本分布 |

## 4. 形式化定义（随用途固化）

- **相邻数据集**：D 与 D′ 相差一位用户在保护窗口 W（默认 90d）内的全部受保护记录（总体方案 §12.3 原样采用 user 级、不是记录级）。
- 每用途声明 (ε, δ) 与窗口；机制默认：计数/占比 → Laplace；连续量 → Gaussian（含裁剪）。
- **贡献裁剪**：每用户每窗口每用途贡献上限 c（默认 c=1 次发布快照）；裁剪在快照构建时执行。

## 5. 隐私预算记账（与金额预算严格分离）

- `dp_purposes` 声明总预算与窗口；每次发布在 `dp_releases` 登记 `epsilon_used/delta_used`，并扣减；余额不足 ⇒ 拒绝发布（`ANET-DSC-DP-EXHAUSTED`）。
- 规则：
  - R5.1 金额预算（05）与隐私预算分别记账，互不挪用；
  - R5.2 已释放的信息不因任务失败而"退回"预算；
  - R5.3 重传**同一**既有 DP 输出 = 后处理，不扣预算；重新访问私有数据生成新输出 = 新发布，重新分析与扣减；
  - R5.4 发布产物（`output_artifact`）不可变；输入快照（`snapshot_ref`）留存以复算。

## 6. 自适应发布的组合控制

若机制或参数会依据既往输出调整（如按近期噪声反馈调权重）：

- 每个发布纪元（默认 7d）内**参数固定**，纪元内为并行组合；
- 跨纪元自适应采用 privacy filters / 阈值监督式记账（已登记的总消耗一旦逼近预算即停），理论依据沿用总体方案 §12.3 引用的自适应组合研究；
- 记账器是唯一扣减入口，发布路径无旁路。

## 7. 可观察输出的声明边界

若路由选择、目录查询模式、时序本身受私有数据影响并对外可见（对端可见我们"查了什么、选了谁"），则这些通道纳入所声明的可观察输出范围并在用途文档中给出界分析；无法给出界分析的通道不得接触私有数据。

## 8. 红线

- 任意自然语言消息经模糊化/加噪后**不得**称为差分隐私（总体方案 §12.3 末条）；
- DP 输出不得反哺任何单任务授权、披露或路由的**个体级**决策（只进聚合估计量）；
- 首版仅实现 §3 表中前两项用途；方向 C（DP + 动态路由）为研究项，不进 MVP 交付（14 §2）。
